I am a Cloud Security and DevOps Engineer passionate about building secure, scalable infrastructure solutions. Currently, I work at Nordea as a Technology Graduate, where I’ve completed three different rotations. My primary focus has been on AWS, where I’ve developed key solutions around domain join, data loss prevention, and security remediation—deploying everything using Infrastructure as Code (IaC) tools like CloudFormation and Terraform. I’ve also emphasized automating tasks with Python and Ansible. While AWS has been my primary focus, I’ve also applied my skills in GCP and Azure environments, especially in AI engineering projects using tools like Gemini Code Assist, Vertex AI and AgentSpace.

Previously, I was a Cyber Security Trainee at Nokia Bell Labs, where my Master’s thesis focused on mapping the public attack surface of mobile communication systems using Open Source Intelligence (OSINT) techniques. I also worked as a Backend Developer Intern at Ericsson, developing features for Ericsson Security Manager. My experience spans software development, cybersecurity, DevOps, and machine learning—giving me a broad perspective that I consider a strength. I enjoy thinking holistically about how technology, security, and scalability converge.

I hold a dual MSc. in Security and Cloud Computing through the Erasmus Mundus SECCLO program, awarded with a fully-funded scholarship. My studies at Aalto University and KTH Royal Institute of Technology laid a strong foundation in areas like cryptography, ethical hacking, and secure cloud systems. These academic foundations have been instrumental in shaping my practical work across diverse roles.

Looking forward, I aim to specialize in platform engineering with a security-first mindset. I’m Also particularly interested in how organizations can responsibly adopt emerging AI technologies while ensuring robust infrastructure, compliance, and security practices. I’m driven by a desire to bridge the gap between cutting-edge innovation and secure, large scale production implementation.

In my free time I like to read, write, travel and hike. I'm active on GitHub and LinkedIn. Feel free to connect!
